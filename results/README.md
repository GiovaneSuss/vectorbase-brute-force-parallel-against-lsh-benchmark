# results/

Saída das execuções: CSV com tempo de execução, speedup, eficiência paralela, recall e métricas de
energia/CPU por configuração (algoritmo x número de threads), conforme a Etapa 6 da especificação técnica.

Gerado pelas execuções via `Makefile`; não versionado no git (ver `.gitignore`) — cada máquina/rodada de
medição produz seus próprios resultados.
